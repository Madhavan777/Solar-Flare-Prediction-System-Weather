What this system does
A leakage-safe Machine Learning pipeline forecasts whether an active region will produce a major (M or X class) solar flare in the 24 hours following a 12-hour observation window, using SHARP magnetic-field parameters from the SWAN-SF benchmark.

Pipeline

SHARP features → 144-dim vector
Split → P1–P3 train / P4 val / P5 test
Models → Logistic Regression, Random Forest
Selection → validation TSS
Output → probability → risk → alert
