Being straight about it

What this is

  • A trained model scoring recorded observations from 2010–2018
  • Checked once on data held back from training, and reproducible from this repository
  • Honest about its mistakes — the failures are on display, not hidden
  • Entirely offline; it works with the network switched off

What this is not

  • Not connected to the Sun, to NASA, or to any feed
  • Not an operational space-weather warning service
  • Not tested beyond 2018 or beyond this one instrument
  • Not a calibrated chance — read it as a ranking, not a percentage

What this system does
A leakage-safe Machine Learning pipeline forecasts whether an active region will produce a major (M or X class) solar flare in the 24 hours following a 12-hour observation window, using SHARP magnetic-field parameters from the SWAN-SF benchmark.

Pipeline

SHARP features → 144-dim vector
Split → P1–P3 train / P4 val / P5 test
Models → Logistic Regression, Random Forest
Selection → validation TSS
Output → probability → risk → alert
